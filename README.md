# Cortez Móveis — Site + Painel Administrativo

Sistema completo da Cortez Móveis: catálogo público de produtos + painel administrativo.

## Tecnologias
- **Frontend:** HTML, CSS, JavaScript (preservando o visual atual)
- **Backend:** Node.js + Express
- **Banco:** PostgreSQL 18 (database: `cortez_moveis`)
- **Segurança:** helmet, bcrypt, cookie HttpOnly, rate limit
